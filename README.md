# 世界时钟

一个可离线使用的世界时间工具，提供交互地球、城市时钟、时区查询与时间计算。

**原生 HTML / CSS / JavaScript · 无后端 · 无构建步骤 · 双击即用**

[开始使用](#开始使用) · [功能](#功能) · [技术栈](#技术栈) · [项目结构](#项目结构) · [开发与验证](#开发与验证) · [数据与使用范围](#数据与使用范围)

## 开始使用

1. 保留 `index.html` 和完整的 `src/` 目录。
2. 双击 `index.html`，在浏览器中打开。
3. 通过顶部导航切换工具；手机端点击导航按钮展开菜单。

无需安装依赖或启动服务器。网站支持 `file://` 和断网使用；部署到静态网站服务器时，同样保持入口与资源的相对路径不变。

## 功能

| 工具     | 可以做什么                                                          |
| -------- | ------------------------------------------------------------------- |
| 交互地球 | 自转、暂停、拖拽、缩放；悬停或点击国家与城市查看时间，首都以 ★ 标记 |
| 城市时钟 | 中英文搜索国家、城市和时区，收藏常用城市并在本地保存                |
| 地区详情 | 查看首都、IANA 时区、UTC 偏移、年度时间调整和地区说明               |
| 时区总览 | 查询 UTC−12 至 UTC+14，包含半小时、45 分钟等非整点偏移              |
| 时间转换 | 指定来源城市或固定偏移，将一个时间换算到多个城市                    |
| 时间推算 | 按天、时、分、秒任意组合向前或向后推算，例如单独输入 100 小时       |
| 时间反查 | 查询此刻哪些时区和内置城市符合目标钟点，支持匹配容差                |

时间转换按所选日期处理夏令时：跳过的当地时间提示重选，重复的当地时间提供不同 UTC 偏移选项。

## 技术栈

| 层面       | 技术与用途                                               |
| ---------- | -------------------------------------------------------- |
| 页面与交互 | HTML5、CSS3、原生 JavaScript；普通脚本按顺序加载         |
| 响应式布局 | CSS Grid、Flexbox、媒体查询                              |
| 地球渲染   | WebGL + GLSL；不可用时回退 Canvas 2D 或静态 SVG          |
| 地理计算   | 本地 d3-geo、d3-array，处理球面投影、裁剪和地理判断      |
| 时间计算   | `Intl.DateTimeFormat`、`Date` 与浏览器内置 IANA 时区规则 |
| 偏好存储   | `localStorage` 保存收藏和显示偏好                        |
| 开发工具   | Node.js、Playwright + Edge、Prettier                     |

所有运行资源均保存在本地。Node.js、Playwright 和 Prettier 仅用于开发，网站使用者无需安装。

## 开发与验证

以下命令均在项目根目录执行。

| 任务             | 命令                               | 环境要求                          |
| ---------------- | ---------------------------------- | --------------------------------- |
| 时间算法回归     | `node tests/time.test.cjs`         | Node.js                           |
| 离线界面验收     | `node tests/browser.test.cjs`      | Node.js、Playwright、Edge         |
| 重新生成国家数据 | `node scripts/build-countries.cjs` | Node.js、`scripts/data/` 原始资料 |

Playwright 不在默认模块路径时，可用 `PLAYWRIGHT_MODULE` 环境变量指定。测试不生成截图或交付包。

代码格式遵循 `.prettierrc.json`，使用 2 空格缩进和 LF 换行；第三方库及生成数据不参与格式化。修改功能时优先定位到对应业务模块，入口 `app.js` 仅负责初始化和刷新调度。

## 数据与使用范围

| 数据               | 来源与说明                                                                                   |
| ------------------ | -------------------------------------------------------------------------------------------- |
| 当前时间           | 设备时钟，不联网校时                                                                         |
| 时区与夏令时规则   | 浏览器 `Intl` 使用的内置 IANA 数据，版本随浏览器或系统更新                                   |
| 地图与首都原始资料 | [Natural Earth](https://www.naturalearthdata.com/)，公共领域；原始文件保存在 `scripts/data/` |
| 城市时区与首都映射 | 项目本地维护                                                                                 |
| 地区说明           | 根据本地资料与计算结果生成，不是 IANA 官方文章                                               |

- 城市库覆盖 **305 座城市**，不代表全球全部城市、地区或时区。
- 日期输入范围为 **1900—2100 年**；历史行政时区与秒级偏移不作为准确性保证范围。
- 时间推算按实际经过时长计算，**1 天 = 24 小时**；跨夏令时后，当地钟点可能改变。
- 使用或分发 d3-geo、d3-array 时，请保留 `src/vendor/` 中的完整许可证。
